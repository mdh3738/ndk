# ndk

Android-host ARM64 NDK + android.jar mirror for Dex2Re Setup downloads.

Release `ndk64` holds the exact files the Dex2Re app downloads (SHA-verified against the app's pinned hashes): `android.jar` (~20 MB) and `ndk_arm64.tar.gz` (~101 MB).
These are the same files as the ispointer/ndk `ndk64` release, re-hosted here so Dex2Re downloads from this repo.
